AVTC

Auckland Voyage Training Camp · Chrome 扩展（Manifest V3）

识别当前 GitHub 仓库，一键在 8 个第三方开发者工具中打开。

AVTC 是一个 URL 路由器：在任意 github.com/{owner}/{repo} 页面点一下扩展图标， 弹窗会读到当前仓库名，把地址改写成 8 个工具的地址并在新标签页直接打开 —— 不显示候选地址、不做二次确认。 地址无效时不会打开任何标签页，只在弹窗底部给出一行文字提示。

8 个动作

  • 理解：看架构图（GitDiagram）· 读项目讲解（DeepWiki）· 用 Zread 解读（Zread）
  • AI 协作：拆成 AI 提示词（GitReverse）· 整理给 AI（Gitingest）
  • 读写代码：在线读源码（GitHub1s）· 在线改代码（GitHub.dev）
  • 运行：尝试在线运行（StackBlitz）

隐私与权限

  • 只申请 storage 与 activeTab 两个权限，安装时无额外权限警告。
  • 扩展自身不发起任何网络请求，不含遥测、不含远程代码、不注入内容脚本。
  • 仓库地址不落盘，只有在你点击某个动作时，才随浏览器跳转发送给对应站点。
